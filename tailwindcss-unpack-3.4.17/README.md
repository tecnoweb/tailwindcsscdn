# TailwindCSS Unpack 3.4.17

Repository contenente la versione unpacked di TailwindCSS 3.4.17 scaricata da [https://cdn.tailwindcss.com/3.4.17](https://cdn.tailwindcss.com/3.4.17).

## 📦 Contenuto

Questa repository contiene il file JavaScript originale di TailwindCSS 3.4.17 così come distribuito dal CDN ufficiale.

## 📁 Struttura

```
tailwindcss-unpack-3.4.17/
├── src/
│   └── tailwindcss-3.4.17.min.js  # File originale minificato
├── docs/                           # Documentazione aggiuntiva
├── package.json                    # Configurazione npm

```

## 🚀 Utilizzo

### Browser (CDN)

```html
<script src="https://cdn.tailwindcss.com/3.4.17"></script>
```

### File Locale

```html
<script src="./src/tailwindcss-3.4.17.min.js"></script>
```

### Node.js / ES Modules

```javascript
import tailwindcss from './src/tailwindcss-3.4.17.min.js';
```
